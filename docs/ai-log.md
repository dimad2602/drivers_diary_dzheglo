# Журнал работы с ИИ

Черновик для раздела README и анкеты. Записываю только то, что реально произошло по ходу работы.

## Как использовался ИИ

- Claude Code (CLI/VS Code) как парный программист: вместе согласовали стек и архитектуру в режиме планирования, затем ИИ писал код и тесты, а я принимал решения и запускал/проверял.
- Референсы (архитектура `mental_app`, дизайн-токены `fusion-ui`) ИИ изучал по моим локальным проектам, чтобы повторить структуру, а не придумывать свою.
- Каждый этап заканчивается запуском тестов и линтера; коммиты делаю я сам.

## Где ИИ ошибся и что исправлено

| Этап | Что пошло не так | Как исправлено |
|---|---|---|
| backend, тесты | Тесты на авторизацию открывали второй `TestClient(app)` через `with`. Выход из `with` запускает shutdown lifespan и сбрасывает in-memory SQLite — следующий запрос падал с `no such table: trips`. | Анонимные клиенты создаются без `with`, а lifespan остаётся на фикстуре `client`. Причину нашли по трейсбеку, а не «подкруткой» теста. |
| backend, тесты | В тесте конфликта дублей ИИ взял `amount=1` при `commission=360` — это нарушает мою же валидацию (комиссия ≤ суммы), и тест падал на создании данных, а не на проверяемой логике. | Тест меняет сумму на валидную (`2500`), чтобы проверять именно 409. |
| backend, зависимости | ИИ по привычке добавил `httpx` как зависимость для `TestClient`. Свежий Starlette выдал `StarletteDeprecationWarning` и требует `httpx2`. | Заменил на `httpx2`, поднял минимальную версию `fastapi`. Знания модели о экосистеме оказались устаревшими — сверяться с предупреждениями тулчейна. |
| backend, скрипт | Скрипт экспорта OpenAPI печатал кириллицу, в консоли Windows получились «кракозябры». | Сообщение стало ASCII. |
